# SafeStart eKYC

Open `index.html` using GitHub Pages or VS Code Live Server.

The website includes:
- Personal loan details
- Simulated Singpass/Myinfo
- Consent
- Fictional personal details
- Employment and income
- Document selection
- Working live camera and photo capture
- Review page
- Simulated fraud, AML and risk checks
- Multiple outcomes and help page

Important: The prototype is educational and is not connected to any real service.
