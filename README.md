# SafeStart eKYC Prototype

A clickable front-end prototype created for the C369 Financial Technologies Final Assessment.

## Features

- User registration and personal information form
- Data consent screen
- Simulated NRIC upload
- Simulated selfie capture
- Animated identity, fraud and AML checks
- Approve, manual review and reject outcomes
- Error-handling and help screens
- Responsive mobile-friendly design

## Important

This is an educational prototype only. It does not connect to a bank, government database, camera service or AML database. No information is sent to a server.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and this README.
3. Open the repository **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for the GitHub Pages link to appear.
